## The entry

A single line — the apology a smart speaker gives its owner after mishearing
"book a table for two" as "book a stable for two":

> Sorry, I heard 'book a table for two' as 'book a stable for two.' The horses arrive at seven. I named one after you.

## How it works

`main.ts` writes that one line (116 characters) to `/output/entry.txt` and
nothing else. Run it with:

```sh
node main.ts
```
